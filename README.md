# NexaSoft Solutions · Módulo Integrado de Gestión de Proyectos y Capacidad

**Integrante:** Brian Switach. Trabajo individual de Organización Empresarial, TUP a Distancia, UTN.

El MGPC permite planificar la capacidad de los equipos, controlar las versiones de los hitos de cada proyecto y avisar a Finanzas cuando el cliente acepta un hito facturable. El cliente sólo puede decidir sobre sus propios proyectos. QA controla la versión antes de que el cliente la reciba.

## Declaración de Uso de IA

Se utilizó ChatGPT. El pedido de Brian fue «HACE TODO ESTO SIGUIENDO AL PIE DE LA LETRA TODO LO QUE SE PIDE Y COMO SE PIDE». También pidió integrar las entregas y conservar la plantilla y el formato PDF. El propósito fue contrastar los antecedentes con las consignas y producir un documento coherente para el coloquio. La instrucción general no especificaba qué caso priorizar cuando surgieran diferencias. La comparación mostró que RutaSur aparecía sólo en la entrega 3, mientras que NexaSoft y el MGPC sostenían el diagnóstico, el alcance y la planificación aprobable de las dos primeras etapas.

La IA adaptó el organigrama y el diccionario al MGPC, formalizó tres necesidades del alcance como historias, diagramó el proceso y mantuvo los umbrales de la entrega 2. La corrección del caso y la separación entre aceptación técnica, aceptación del cliente y aviso financiero fueron realizadas con asistencia de IA. No se registraron todavía correcciones humanas a este cierre. Se documentarán en la revisión real, indicando decisión, motivo y cambio aplicado. El estudiante conserva la responsabilidad intelectual de la presentación.
