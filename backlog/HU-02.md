# HU-02 · Aceptar una versión

Como cliente, quiero aceptar u observar una versión que superó QA, para dejar constancia de si cumple el alcance acordado.

## Criterios de aceptación

Una observación exige motivo y conserva la versión. Un usuario de otro cliente no puede consultar ni decidir el hito. Una respuesta a una versión anterior no cambia la vigente.
